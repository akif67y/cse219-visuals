Sampling and the Discrete Fourier Series

Multiply a continuous periodic signal by an impulse train and only N samples per period survive. Take the Fourier series of what is left: the integral collapses to a sum, and the coefficients repeat forever with period N.

ck = 1⁄T₀ Σ x[n]e−j2πkn/N

1Sample with an impulse train

xp(t) = x(t)·p(t) keeps only the values x[n] = x(nTₛ). One period T₀ holds exactly N of them.

continuous x(t) impulse train p(t), spacing Tₛ samples x[n] = x(nTₛ)
The impulse train is a switch: between samples, xp(t) is zero, so the Fourier-series integral only ever “sees” the N sample values. That is how ∫ becomes Σ.

2Fourier series of the sampled signal — an N-periodic spectrum

ck computed from the N samples, plotted far beyond one period. Shaded: the window k = 0 … N−1 that we keep — the seed of the DFT.

|ck| in the kept window 0 … N−1 the same N values, repeating harmonics of the continuous x(t)
Only N numbers exist. Because e−j2π(k+N)n/N = e−j2πkn/N, coefficient k+N is coefficient k all over again. Sampling in time made the spectrum periodic — hover any stem to see which unique coefficient it copies. The orange markers are the true harmonics of x(t): inside the central window they coincide with ck as long as the copies don’t overlap.
